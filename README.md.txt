Task 1: Data Cleaning and Preprocessing

Objective

Clean and prepare the Netflix Movies and TV Shows dataset by handling missing values, removing duplicates, standardizing formats, and improving overall data quality.

Dataset

Netflix Movies and TV Shows Dataset

Tools Used

* Microsoft Excel
* GitHub

Data Cleaning Steps Performed

1. Checked for duplicate records and removed duplicates where necessary.
2. Identified missing values in columns such as director, cast, country, date_added, and rating.
3. Replaced missing categorical values with appropriate placeholders such as "Unknown" and "Not Rated".
4. Standardized date formats in the date_added column.
5. Renamed column headers using lowercase letters and underscores.
6. Verified data types and reviewed text columns for consistency.
7. Performed final validation to ensure data quality.

Files Included

* Original Dataset
* Cleaned Dataset
* README.md

Outcome

The dataset was cleaned and prepared for further analysis and visualization.
